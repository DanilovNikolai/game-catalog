# Game Catalog

A web platform for cataloging physical video game editions and managing personal game collections.

## About the project

Game Catalog is a fullstack web application focused on physical editions of video games.

The platform allows users to explore a public catalog, search and filter editions, manage personal collections, create wishlists, and contribute to catalog improvements through a moderation system.

## Planned features

- Public catalog of physical video game editions
- Search, filtering, and sorting
- Personal game collections
- Favorites and wishlists
- User authentication and role-based access control
- Community-submitted catalog changes
- Moderation and change history
- Notifications and announcements
